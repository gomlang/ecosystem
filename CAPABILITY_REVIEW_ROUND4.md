implementations, documented limits and focused existing tests. The
[preceding round](CAPABILITY_REVIEW_ROUND3.md) and
[earlier review](CAPABILITY_REVIEW.md) retain their original delivery records.

candidates** and **12 deliberate scope boundaries**. A separate CSV documentation
correction brings the number of changed library repositories to **13**.
Libraries changed in the preceding round were checked for their next missing
capability. All source references are pinned to reviewed revisions.

## Validation and cross-review

All 12 libraries with functional changes passed local `goml fmt --check`,
`goml test --timeout 300s`, `goml verify --timeout 300s` and `git diff --check`,
using GoML 0.1.57 and Go 1.26.8. Independent consumer verification uses isolated
registry snapshots. The final CI runs apply the existing pinned verification
workflow to each exact candidate commit.

Focused validation includes:

- ZIP DOS timestamps: independent Python zipfile/datetime vectors, leap-century boundaries, offset extremes, invalid dates and Unix-extra-field precedence in both memory and ReadAt APIs.
- ASN.1 INTEGER: positive/negative values beyond i64, shortest sign encoding, malformed TLVs, length transitions, exact budgets and detached byte storage.
- Cache batch writes: prevalidation without side effects, duplicate-key ordering, expiration, eviction, load invalidation, callback reentry and copied input/value ownership.
- Fuzzy collection search: exact/prefix/suffix/substring modes, parallel consistency, mode changes, safe incremental narrowing, smart case and zero Top-K.
- Graph generations: parallel edges, deleted slots, isolated nodes, cycle errors and all 512 three-node directed graphs checked against an independent reachability/longest-path reference.
- Prometheus export: exact byte budgets, short/zero/invalid writes, original I/O errors, partial-output behavior, callback mutation and snapshot consistency.
- ELF notes: eight independent ELF32/ELF64 fixtures spanning byte order and 4/8-byte alignment, readelf checks, malformed lengths, quotas and ownership.
- Prompt ranking: stable ties, hidden/disabled selections, ordering, query changes, callback inputs and existing default search behavior.
- Regex callbacks: literal returned text, captures, Unicode empty matches, typed callback failures, panic propagation and shared work/output bounds.
- Header mutation: duplicate replacement position, removal counts, canonical keys, invalid-input atomicity, shared aliases, owned byte snapshots and wire roundtrips.
- Monotonic UUIDs: equal/regressing clocks, both counter carries, complete exhaustion, source errors/panics, timestamp extremes and 512 concurrent allocations from shared aliases.
- Repeated XML scalars: absent/empty members, interleaved fields, namespaces, signed/unsigned boundaries, configuration conflicts, strict shape checks and exact token/output limits.

Cross-review found that a cache value-copy callback could mutate the original
batch after validation. The implementation now snapshots the input entries
before validation and callback execution; regression tests cover replacement
and clearing of the caller-owned vector. All four groups received a separate
implementation review, including the new UUID counter and XML cardinalities.

The CSV change only corrects documentation; its full local runtime suite was
not rerun, and its final CI succeeded. The remaining **55 unchanged libraries**
received API/implementation/test review without rerunning their full runtime
suites locally. Historical split manifests and the pinned verifier inventory
remain unchanged.

## Candidates for another round

Remaining candidates that can be designed independently include:

1. `mail`: checked formatting for mailbox and group structures, including encoded display names.
2. `x509`: a bounded Subject Alternative Name codec with explicit GeneralName policies.
3. `datetime`: format-pattern parsing with field-conflict and timezone-offset rules.
4. `go_doc`: a caller-supplied symbol-link resolver for documentation sites.
5. `csv`: opt-in dialect inference with sample limits and ambiguity reporting.
6. `xml`: nested-struct mappings with explicit namespace and cardinality contracts.
7. `tui_markdown`: configurable search behavior with stable source-to-layout matches.
8. `tabwriter`: an ANSI-aware or custom width policy retaining original cell content.

Each candidate needs its own contract and reference cases. Larger protocol,
platform, numerical and presentation-tree expansions remain listed above.
