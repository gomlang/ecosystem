# Library capability review — 2026-10-04

This review covers all **68 importable libraries** in [catalog.json](catalog.json).
Public APIs, implementation paths, documented limits and focused existing tests
were inspected to identify concrete missing capabilities. Source references
below are pinned to the reviewed or delivered revisions.

**12 improvements were implemented**, **44 candidates were deferred**, and
**12 findings describe deliberate scope boundaries**. A deferred entry records
the next design or validation work needed. A scope entry describes a capability
that needs an explicit expansion of the library contract.

## Validation

All 12 changed libraries passed local `goml fmt --check`, `goml test --timeout 300s`, `goml verify --timeout 300s` and `git diff --check`, using GoML 0.1.57
and Go 1.26.8. `verify` built and tested the example as an independent consumer
through an isolated registry. The linked GitHub Actions runs verify the exact
delivered commits with the existing pinned verification infrastructure. All 12
linked runs completed successfully.

Focused checks include:

- ANSI ambiguous-width glyphs, grapheme boundaries, styles and hyperlinks.
- DER BIT STRING padding, tag/length canonicality, budgets and detached data.
- Cache batch ordering, duplicate keys, expiry, LRU/statistics and callbacks after unlocking.
- Undirected cycles checked against every simple four-node graph, plus parallel edges, self-loops and a deep graph.
- HTTP request framing conflicts, malformed transfer lists, zero/duplicate lengths and header injection.
- Image orientation golden vectors, inverse transforms, nonzero bounds, alpha and independent pixel storage.
- Pipeline early stop, accumulated values, source release, task joins, errors and cancellation.
- Literal regex replacements with dollar/backslash text, Unicode empty matches and shared budgets.
- Reverse rope lines with CR/LF/CRLF across leaves, empty/trailing lines and large shared snapshots.
- Text replies with exact wire budgets, invalid later lines, raw bytes, dot-state conflicts and sink failure.
- GUID field byte order, every individual bit, invalid lengths and input/output alias isolation.
- Directory ordering with depth/pruning, deterministic ties and comparator-triggered close/cancellation.

Cross-review also found and fixed the combined close-and-cancel case in the
directory comparator. Explicit close now keeps the iterator exhausted in both
preorder and contents-first traversal.

The remaining 56 libraries received API/implementation/test review; their full
runtime suites were not rerun in this round. Historical split manifests and the
pinned verification inventory remain the existing migration/CI baseline.

## Candidates for the next implementation round

These candidates build on current APIs and can be developed independently:

1. `mime`: bounded discard of the current multipart body, preserving source-error and byte-budget behavior.
2. `tabwriter`: explicit per-column alignment for numeric tables.
3. `csv`: opt-in comment handling with quoted-field and physical-record rules.
4. `go_doc`: automatic URL links with Go doc-comment boundary fixtures.
5. `mail`: a structured address-list API retaining group labels and empty groups.
6. `parser`: a binary sentinel-terminated collection combinator with partial-input semantics.
7. `x509`: bounded typed Subject Alternative Name and Extended Key Usage codecs.
8. `lsp`: typed completion, semantic-token and workspace-edit helpers over the existing router.

Each candidate still needs its own API review and independent reference cases.
Larger work such as distributed trace propagation, new HTTP transports,
cross-platform filesystem backends, numerical solvers and lossless YAML
presentation trees is recorded in the table with the required design scope.
